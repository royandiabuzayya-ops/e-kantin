Panduan Google Apps Script

1. Buka Google Sheet baru di browser.
2. Klik menu Ekstensi > Apps Script.
3. Hapus semua kode, lalu paste kode berikut:

4. Klik Terapkan (Deploy) > Penerapan Baru.
5. Pilih jenis Aplikasi Web, ubah *Akses Siapa Saja* menjadi Siapa saja (Anyone).
6. Copy URL Aplikasi Web dan paste ke menu Pengaturan.

Penting! Pastikan mengganti kode Apps Script yang lama dengan yang ada di atas karena terdapat pembaruan penyaring untuk data yang dihapus (tombstone filter). Jangan lupa untuk Deploy > Kelola Penerapan > Ikon Pensil > Versi: Baru > Deploy.

Konfirmasi Reset Data

Apakah Anda yakin ingin menghapus seluruh data kantin secara permanen? Data yang dihapus tidak dapat dikembalikan.
